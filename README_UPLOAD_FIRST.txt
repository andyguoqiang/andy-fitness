ANDY'S FITNESS OS — CLEAN GITHUB REUPLOAD

Your repository root must contain exactly:
  index.html
  manifest.json
  sw.js
  .nojekyll
  assets/   (folder containing all PNG files)

IMPORTANT:
- The home page file MUST be named exactly index.html.
- Do not rename it to andy_fitness_os_...html.
- Do not delete index.html.
- Upload the CONTENTS of this extracted folder, not the ZIP file.
- Open the assets folder in this package and confirm it contains the PNG files.

Recommended cleanup in GitHub before uploading:
1. Delete the misnamed HTML file (for example andy_fitness_os_v9_1_index.html).
2. Delete assets/test.txt.
3. Keep or replace manifest.json and sw.js.
4. Upload index.html and the complete assets folder.
5. Commit the changes.
6. Wait for the green “pages build and deployment” checkmark.
7. Open https://andyguoqiang.github.io/andy-fitness/

If GitHub's browser upload will not accept the assets folder:
- Open the assets folder on GitHub.
- Click Add file → Upload files.
- Drag every PNG from this package's assets folder into that page.
- Commit.
